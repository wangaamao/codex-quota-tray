Codex Quota Tray 1.3.3

Compact fonts follow the Windows desktop text setting and display DPI.
The window opens at the current screen's bottom-right usable corner.
Quota refresh defaults to 5 minutes and can be set to 1, 3, 5, or 10 minutes from the right-click menu.
A failed refresh is retried up to three times before the normal schedule resumes.
Double-click the floating label to refresh immediately.
The right-click menu can open GitHub and shows the current and latest release versions.
