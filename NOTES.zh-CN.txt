Codex 余量条 1.3.3

紧凑字体会跟随 Windows 桌面文字设置和显示 DPI。
窗口启动时会吸附到当前屏幕可用工作区的右下角。
默认每 5 分钟刷新，可在右键菜单中选择 1、3、5 或 10 分钟。
一次刷新失败后最多连续重试 3 次，之后恢复正常刷新周期。
双击悬浮标签可以立即刷新数据。
右键菜单可以打开 GitHub，并显示当前版本和最新发布版本。

用途：与发布版 EXE 放在一起的简体中文快速使用说明。

搜索关键词：Codex、余量、剩余用量、ChatGPT、ChatGPT Codex、使用限额、
5 小时余量、一周余量、重置时间、限额监控、Windows 任务栏插件、
Codex quota、remaining usage、usage limits、rate limit monitor。

双击 CodexQuotaTray.exe 运行。双击悬浮标签可以立即刷新；右键可以
选择刷新间隔、打开 Codex 或 GitHub、查看版本信息或退出。

运行要求：
- Windows 10 或 Windows 11
- 已安装 Codex CLI 或 VS Code 的 OpenAI Codex 扩展
- 当前 Windows 用户已经登录 Codex

本应用不会包含、复制、导出或上传任何登录凭据。
准确的隐私和网络行为说明请阅读 README.zh-CN.md。
